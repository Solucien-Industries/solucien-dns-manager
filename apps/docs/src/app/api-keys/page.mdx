# API keys

API keys allow scripts and CI pipelines to call protected endpoints without an interactive login. {{ className: 'lead' }}

## List keys

<CodeGroup tag="GET" label="/api/api-keys">

```bash {{ title: 'cURL' }}
curl http://localhost:4000/api/api-keys \
  -H "Authorization: Bearer YOUR_JWT"
```

</CodeGroup>

## Create a key

<CodeGroup tag="POST" label="/api/api-keys">

```bash {{ title: 'cURL' }}
curl -X POST http://localhost:4000/api/api-keys \
  -H "Authorization: Bearer YOUR_JWT" \
  -H "Content-Type: application/json" \
  -d '{"name":"Terraform"}'
```

</CodeGroup>

## Revoke a key

<CodeGroup tag="DELETE" label="/api/api-keys/{id}">

```bash {{ title: 'cURL' }}
curl -X DELETE http://localhost:4000/api/api-keys/key_abc123 \
  -H "Authorization: Bearer YOUR_JWT"
```

</CodeGroup>
