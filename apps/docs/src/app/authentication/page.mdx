# Authentication

All protected endpoints require a bearer token in the `Authorization` header. {{ className: 'lead' }}

## Session JWT (recommended for the web app)

After OAuth or preview login, the Next.js app exchanges the session for a JWT:

```bash {{ title: 'Exchange (server-side only)' }}
POST /api/auth/login
X-Auth-Exchange-Secret: YOUR_EXCHANGE_SECRET
Content-Type: application/json

{ "email": "ops@example.com", "name": "Ops User" }
```

Use the returned `accessToken` as:

```bash
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

## API keys (automation)

Generate keys in **Settings → API** in the Nani console, or via:

<CodeGroup tag="POST" label="/api/api-keys">

```bash {{ title: 'cURL' }}
curl -X POST http://localhost:4000/api/api-keys \
  -H "Authorization: Bearer YOUR_JWT" \
  -H "Content-Type: application/json" \
  -d '{"name":"CI deployment"}'
```

</CodeGroup>

The response includes a `secret` shown **once**. Store it securely.

<Note>
  Never commit JWT secrets, exchange secrets, or API keys to git.
</Note>
