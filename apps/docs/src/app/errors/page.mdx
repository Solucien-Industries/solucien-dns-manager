# Errors

The Nani API uses standard HTTP status codes and JSON error bodies from NestJS validation. {{ className: 'lead' }}

## Common status codes

| Status | Meaning |
| --- | --- |
| `400` | Invalid request body or query parameters |
| `401` | Missing or invalid bearer token |
| `403` | Invalid auth exchange secret (login route) |
| `404` | Domain, record, or API key not found |
| `502` | Upstream failure (PowerDNS/Postgres unavailable) |

## Example error body

```json {{ title: 'Validation error' }}
{
  "statusCode": 400,
  "message": ["name must be a valid domain"],
  "error": "Bad Request"
}
```

## Tips

- Ensure `Authorization: Bearer` is set on protected routes
- Domain names must be fully qualified (`example.com`, not `https://example.com`)
- API key secrets are only returned once at creation time
