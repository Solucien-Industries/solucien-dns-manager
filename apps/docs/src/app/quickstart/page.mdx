# Quickstart

This guide walks through authentication and your first authenticated request. {{ className: 'lead' }}

<Note>
  Start the stack with `npm run dev` from the monorepo root. Web runs on port 3000, API on 4000, docs on 3001.
</Note>

## 1. Sign in or use preview mode

Use the Nani console at `http://localhost:3000` and choose **Preview authenticated dashboard**, or sign in with Google/GitHub when OAuth is configured.

The browser receives a JWT via the `/api/auth/token` exchange route.

## 2. Make an authenticated request

<CodeGroup tag="GET" label="/api/dashboard">

```bash {{ title: 'cURL' }}
curl http://localhost:4000/api/dashboard \
  -H "Authorization: Bearer YOUR_JWT"
```

```js {{ language: 'js' }}
const res = await fetch('http://localhost:4000/api/dashboard', {
  headers: { Authorization: 'Bearer YOUR_JWT' },
})
const data = await res.json()
```

</CodeGroup>

## 3. Create a domain

After creation, update nameservers at your registrar to `ns1.nani.dns` and `ns2.nani.dns`.

<CodeGroup tag="POST" label="/api/domains">

```bash {{ title: 'cURL' }}
curl -X POST http://localhost:4000/api/domains \
  -H "Authorization: Bearer YOUR_JWT" \
  -H "Content-Type: application/json" \
  -d '{"name":"example.com","owner":"Your Organization"}'
```

</CodeGroup>
